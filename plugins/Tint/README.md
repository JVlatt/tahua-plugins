# Tahua Tint

Hue shift, saturation and invert

| | |
|---|---|
| **Type** | Effet |
| **ID FFGL** | `TE01` |
| **Fichier** | `TahuaTint.dll` (Windows) / `TahuaTint.bundle` (macOS) |

## Paramètres

| Nom | Type | Plage | Défaut | Description |
|---|---|---|---|---|
| Hue | Standard (slider) | 0 – 1 | 0 | Rotation de teinte (1 = tour complet) |
| Saturation | Range | 0 – 2 | 1 | Multiplicateur de saturation (0 = noir et blanc) |
| Invert | Booléen | on/off | off | Inverse les couleurs après teinte et saturation |

## Compatibilité

- Resolume Arena / Avenue 7.3.1 ou plus récent (FFGL 2.x)
- Windows 10/11 x64
- macOS 10.15 ou plus récent, Intel et Apple Silicon (binaire universel)
